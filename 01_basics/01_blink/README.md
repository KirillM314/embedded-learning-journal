# Project 01: Blinking LED

## Description
Simple blinking LED on Arduino Nano (pin 9). First embedded project.

## Components
- Arduino Nano
- LED (red)
- Resistor ~970 Ω (temporary)
- Breadboard, wires

## Wiring
- Pin D9 → LED anode (long leg)
- LED cathode → resistor ~970 Ω
- Resistor other end → GND
